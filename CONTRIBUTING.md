# Contributing to ShareFare

First off, thank you for considering contributing to ShareFare! It's people like you that make this community such a great place.

## How to Contribute

### 1. Fork the Repository
Click the "Fork" button at the top right of the repository page to create your own copy of the project.

### 2. Create a Branch
```bash
git checkout -b feature/your-amazing-feature
```

### 3. Make Your Changes
Write your code, add tests if applicable, and ensure everything runs smoothly locally.

### 4. Commit Your Changes
Use clear, descriptive commit messages.
```bash
git commit -m "feat: add amazing new feature"
```

### 5. Push to Your Fork
```bash
git push origin feature/your-amazing-feature
```

### 6. Open a Pull Request
Go to the original ShareFare repository and open a Pull Request against the `main` branch. Provide a clear description of what your changes do.

## Code of Conduct
Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms. Be respectful, kind, and collaborative!

Thank you for your contributions!
